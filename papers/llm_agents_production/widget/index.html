  1. Choose an architecture and experiment family.

Definitions

Local workers
Parallel local tasks processing independent records.
Hosted API concurrency
Maximum simultaneous hosted model or retrieval calls.
Batch concurrency
Records processed at the same time in the multi-agent workflow.
Verifier concurrency cap
Maximum simultaneous verifier-stage model calls.
Prediction yield
Share of records that produce a usable predicted label set.
Strict agreement
Exact match between predicted and reference label sets.
Peak tokens/min
Peak tokens per minute (TPM), used as a token-pressure proxy.
Pareto-relevant
Not clearly dominated across cost, throughput, yield, and agreement.
